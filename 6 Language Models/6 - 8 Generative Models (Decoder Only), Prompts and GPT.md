# Generative Models (Decoder-Only), Prompts and GPT

Generative Models are **Decoder-Only Models**, and have started a new revolution in Artificial Intelligence with the release of GPT-3 in 2020. We will come to learn how these models work, and what problems they solve.

Consider the *Supervised Learning* Task $f: X \rightarrow Y \space \forall (x_i,y_i)$

We can solve $f$ by training the output of a language model s.t $x_i \in c \rightarrow y$.

In addition to $x_i$ we can inject **prompts** to describe our natural language goal.

## Prompt Engineering

Not all prompts are equal. They need to be *unambiguous* and suppose a reasonable continuation.

Due to the stochasity of LLMs outputs it is difficult to add hard **constraints** in a prompt that are strictly enforced. We should expect post-processing of outputs.

Prompting can be viewed as is *in-context learning*.

### Example

1. adding a statement to get desired output
	1. "Did not like the service that I was provided, when I entered the hotel. I also did not like the area, in which the hotel was located. Too much noise and events going on for me to feel relax. In short, our stay was"
	2. Output: not a pleasant one. The staff at the front desk were not welcoming or friendly, and seemed disinterested in providing good customer service.
	3. -> We can infer the sentiment from the text the LLM outputs
2. Constraints

	- Do you think that "input" has negative or positive sentiment? Choices:
	- (P) Positive (N) Negative
	-  believe the best answer is:
		- (This should prompt the LLM to continue the sentence with P
		- N...

3. Summarisation {input}; tldr;
4. Translation {input}; translate to French:
5. Sentiment {input}; Overall, it was
6. Fine-Grained-Sentiment {input}; What aspects were important in this review?

### Templating

If we want to address multiple tasks with one prompt we can use templates for the input.

- Original Review ($INPUT) Did not like the service that I was provided, when I entered the hotel. I also did not like the area, in which the hotel was located. Too much noise and events going on for me to feel relax and away from the city life
- Sentiment
	- Prompt: $INPUT + In short, our stay was
	- Output: not enjoyable
- Summarisation
	- Prompt: $INPUT + tl;dr
	- Output: I had a bad experience with the hotel’s service and the location was loud and busy

Additional

- restrict a summary to a particular length
- answer according to a persona or role (you are a chatbot... you are an assistant...)
- specify a structured output (JSON formatting)

### Zero-Shot v Few-Shot prompting

Prompting with instructions only corresponds to zero-shot
learning (doing learning without providing any example). We can also provide examples (demonstrations) to help make
the instructions clearer
	"Give the sentiment of the following sentence. Example Input: ’I really loved Taishan Cuisine’ Output: positive"

The primary benefit is to demonstrate the task to be performed to the LLM and the format of the output sequence (only few example suffice). Adding too many examples seems to cause the model to over-fit to details of the exact examples chosen and generalise poorly.

- Using demonstrations that are similar to the current input seems to improve performance.
- Prompting seems to correspond teaching the LLM how to perform a task, prompting is referred to as in-context learning

### Chain-of-thought Prompting

Chain of thought prompting was devised to improve the performance of decoder-only models on reasoning tasks, by mimicking the way humans break down tasks into multiple steps.

- Simple method: add to each demonstration from instruction tuning more text that explains the reasoning steps.

### Optimisation

Prompt optimisation techniques require

1. a start state
	1. a prompt generated by  human or machine
2. a scoring function
	1. e.g accuracy
3. an expansion method
	1. to generate variations of the prompt
	2. e.g generating parphrases
	3. asking LLM to critque the current prompt
4. evaluate on subset of data.

### Limitations

Consistent generation with context may not always be forced with prompting.

solutions:

- Instruction Tuning: finetune on a courpus of instructions and questions with corresponding responses
- Preference alignment (Human feedback reinforcement learning)
	- this is what chat-GPT does.
	- a separate model is trained to decide how much a candidate response aligns with human preferences which fine tunes the base model

#### Instruction Tuning
A supervised learning techniuqe where:

- training date is a set of instructions (pompts and input/output pairs)

We penalise outputs of the LLMs that do not correspond to the procided with *cross entropy loss*.

Evaluation is performed on a test task not used during training.

Datasets:

- Aya gives 503 million instructions in 114 languages from 12 tasks including question answering, summarization, translation, paraphrasing, sentiment analysis.
- Partly manually curated, partly adapted from existing annotated datasets (for example using annotation guidelines).

## History of GPT

Generative Pretrained Transformer (GPT).

- Transformer decoder
	- with 12 layers; 768-dimensional hidden states, 3072-dimensional feed-forward hidden layers;
- Byte-pair encoding with 40,000 merges;
- Trained on BooksCorpus: over 7000 unique books
- GPT-2 (1.5 billion parameters) is based on transformer’s decoder-only, no cross-attention layer. Layer normalization moved to the input of each sub-block.
- GPT-3 (175 billion parameters) is the same model with slight differences: includes (causal) attention sparsity at half of the layers, computing only a subset of the elements of the attention matrix.
- GPT-3 has been trained on
	- Common Crawl dataset (nearly a trillion words) WebText dataset
	- book corpora
	- English-language Wikipedia
- Prompting on GPT-3 showed promising results
- An enhanced version of GPT-3 named GPT-3.5 has been used as a basis for the chatBot chatGPT.
